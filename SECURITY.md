# Security Policy

## Supported versions

Security fixes are released for the current major version only.

| Version | Supported          |
|---------|--------------------|
| 10.x    | Yes                |
| < 10.0  | No                 |

If you are on an older major version, upgrade to the latest 10.x release to
receive security fixes.

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Report them privately through
[GitHub Security Advisories](https://github.com/udndc/X.PagedList/security/advisories/new)
for this repository (private vulnerability reporting).

Include as much of the following as you can:

- the affected package(s) and version(s),
- a description of the issue and its impact,
- steps to reproduce or a proof of concept.

## Response

The project is maintained by one person in his spare time. Expect an initial
response within **5 working days** (best effort). You will be kept informed
about the progress of a fix and the planned disclosure. Fixes are published
as a patch release of the current major version together with a GitHub
Security Advisory.

## Versioning

X.PagedList follows [Semantic Versioning 2.0](https://semver.org/spec/v2.0.0.html):

- **Major** — breaking changes to the public API or supported target frameworks.
- **Minor** — new features, backward compatible.
- **Patch** — bug fixes and security fixes, backward compatible.
